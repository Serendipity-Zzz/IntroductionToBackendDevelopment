# 内存后端演示版

Java21以上，在IDEA打开pom.xml，运行SignupApplication，访问http://127.0.0.1:8082/。也可构建后运行target/signup-memory-1.0.0.jar。不需要MySQL、DB_PASSWORD或建表。

zhh、myh的密码均为demo123，原演示账号保留。不同浏览器共享同一个Java进程的账号和报名；刷新网页不清空报名。停止并重新启动Java后，新增账号与报名全部消失，内置演示账号重新初始化。登录token也失效，需要重新登录后再看“我的报名”。

为了避免两个请求同时占用最后一个名额，报名入口使用同一进程中的同步控制。内存数据没有序列化到磁盘，这个版本专门用于对照演示；Apifox实操使用完整工程8080。
