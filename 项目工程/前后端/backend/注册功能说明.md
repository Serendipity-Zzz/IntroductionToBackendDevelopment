# 注册与登录

网页入口增加“注册账号”。填写称呼、账号、密码与确认密码，成功后回到登录页，自动填好新账号，再用新密码登录。zhh和myh仍可用于开场演示。

账号为3至32位英文字母、数字或下划线，以字母开头，统一按小写保存；称呼最多32个字符；新密码为8至64个字符，UTF-8编码不超过72字节。重复账号返回409与USERNAME_TAKEN。演示账号的旧密码demo123继续有效。

新增接口：POST /api/auth/register，JSON正文例如：

```json
{"username":"charlie","displayName":"陈同学","password":"classroom123"}
```

返回201与账号的id、username、displayName，不返回密码或密码哈希。注册本身不创建登录会话，随后调用原登录接口获取token。MySQL保存BCrypt密码哈希，username唯一约束负责拦截同时提交的重复账号。

## 已有数据库先升级一次

新库的users.id已使用AUTO_INCREMENT。如果沿用修改前的signup_demo或signup_lab，请用自己的MySQL管理员连接，选中对应库，再执行sql/03_已有数据库启用注册.sql；两个库分别执行一次。脚本保留已有账号和报名记录。课堂workshop账号无ALTER权限，因此需要管理员执行。

未升级时，注册接口会返回503与ACCOUNT_SCHEMA_UPDATE_REQUIRED，提示执行这份脚本；原账号仍可登录。不要通过删库来升级。

## 纯前端对照的保存范围

两版界面和注册步骤一致。纯前端将新账号及加盐派生的密码校验值放在当前浏览器的localStorage，刷新后可以重新登录；它仍属于可由用户修改的本机演示数据，不作为真实身份验证。不同浏览器不共享这些账号。

为保留“页面内存与数据库”的课堂对照，纯前端的报名记录仍只保存在当前页面，刷新后会消失。后端版的账号与报名都写入MySQL，重新登录可以查回。
